# 足球预测台 / Forecast Desk

足球赛事概率预测台：Dixon-Coles 双泊松 + World Football Elo + 蒙特卡洛。页面是一个零依赖的单文件应用（`index.html`），数据是 `web/data/` 下预先算好的 JSON。
A forecasting desk for football: Dixon-Coles bivariate Poisson + World Football Elo + Monte Carlo. The page is a zero-dependency single-file app (`index.html`); the numbers are pre-computed JSON under `web/data/`.

2026 世界杯那套页面已归档到 `/wc2026.html`，不再更新。
The 2026 World Cup page is archived at `/wc2026.html` and is no longer updated.

## 是什么 / What it is

- **总览页 `#/`**：按日期自动把赛事分成「进行中」「尚未开赛」「已结束（归档）」。每个赛事一行：进度、夺冠概率带、前三名热门、数据截止日。所以新赛事只要在 `web/data/` 里有 JSON 并进了 `index.json`，就会自动出现在总览里，不用改前端。
  **Overview `#/`**: events are split into live / upcoming / finished by date. One row per event with progress, a title-probability band, the top three and the data cutoff. A new event only needs its JSON in `web/data/` and an entry in `index.json`; the page picks it up automatically.
- **赛事页 `#/e/<id>`**：联赛给积分榜、名次概率热力表、未来 14 天模型 vs 市场、可信度；国家队赛事给夺冠与晋级、小组、淘汰赛、赛程、可信度；欧战（欧冠联赛阶段 `kind: swiss`、解放者杯 `kind: groups2leg`）给「联赛阶段/小组赛、淘汰赛、赛程、可信度」，市场列固定显示「—」。
  **Event page `#/e/<id>`**: leagues get table, finish-position heatmap, next-14-day model vs market, reliability; international tournaments get title & progression, groups, knockout, fixtures, reliability; European events (Champions League league phase `kind: swiss`, Copa Libertadores `kind: groups2leg`) get league-phase/group tables, knockout odds, fixtures and reliability, with the market column always "—".
- **方法与可信度 `#/method`**：模型、数据、训练/测试划分，以及用真实 JSON 渲染的比赛级和赛季级两张检验表。
  **Method `#/method`**: model, data, train/test split, plus the match-level and season-level test tables rendered from the real JSON.
- 中文是默认语言，右上角可切英文；「夜场」切深色。所有概率都来自 JSON，页面上没有手抄的数字。
  Chinese is the default language, English toggles in the header; "夜场" switches to dark. Every probability comes from the JSON.

## 数据从哪来 / Where the data comes from

| 数据 / Data | 来源 / Source | 落地 / Where |
|---|---|---|
| 国家队比赛（1872 年至今全部 A 级赛） | [martj42/international_results](https://github.com/martj42/international_results)（CC0） | `npm run engine:fetch` → `data/history/`（不入库） |
| 俱乐部比赛（五大联赛 + 葡超、荷甲、比甲、苏超两级、土超、希超，22 个赛季） | [football-data.co.uk](https://www.football-data.co.uk/) CSV | `npm run engine:fetch-clubs` → `data/clubs/`（不入库） |
| 欧战比赛（欧冠联赛阶段、解放者杯） | [football-data.org](https://www.football-data.org/) v4 免费档（`X-Auth-Token` 在 `data/api-keys.json` 的 `football-data`，该文件 gitignore） | `npm run engine:fetch-euro` → `data/uefa/`（不入库，6 小时缓存） |
| 市场概率 | Pinnacle / 平均收盘赔率，按比例去抽水 / de-vigged closing odds | 随 `data/clubs/` 一起下载；欧战免费档没有赔率 |
| 页面数据 | 由引擎生成 / generated by the engine | `web/data/<赛事 id>.json` + `web/data/index.json`（入库） |

每个赛事 JSON 都带 `asOf`（模型生成日）、`dataThrough`（数据截止日）、`sims`（模拟次数）、`seed`、`model`（参数）和 `validation`（检验结果）。页面只读这些字段。
Every event JSON carries `asOf`, `dataThrough`, `sims`, `seed`, `model` and `validation`; the page reads only those fields.

## 加新赛事 / 加新赛季

**新的国家队赛事 / a new international tournament**

1. 复制 `engine/events/asian-cup-2027.json`，按官方来源填分组、东道主、淘汰赛对阵；有官方第三名组合表就逐行抄进 `sources`。
2. `npm run engine:simulate -- <赛事 id>` → 写 `web/data/<id>.json` 并重建 `index.json`。
3. `npm run test:engine`；页面不用改。

1. Copy `engine/events/asian-cup-2027.json`, fill groups, host and bracket from official sources; copy the official third-place table row by row if it exists.
2. `npm run engine:simulate -- <event id>` writes `web/data/<id>.json` and rebuilds `index.json`.
3. `npm run test:engine`. The page needs no change.

**新的联赛赛季 / a new league season**

1. `scripts/refresh.sh`（或直接 `node engine/cli.js refresh`）先拉到当季数据；新赛季踢过一轮后跑 `node engine/cli.js new-season --season 2728`：按数据里已出现的球队自动生成七份 `engine/leagues/*.json`（id、赛季、队数、区间都重算；已有同名文件不覆盖，确认要重写加 `--force`）。**队数护栏**：新赛季见到的队数少于模板的 75% 直接拒绝（数据不全，`--force` 也不写）；与模板不同但过线只警告，要 `--force` 才写。
2. 再跑一次 `node engine/cli.js refresh`：国家队赛事 + 在赛联赛一起刷新，重建 `web/data/*.json` 与 `index.json`。
3. 页面自动列出；赛季结束后（5 月 31 日）自动跳过并进归档；缺中文名的球队会在输出里列出来，补进配置的 `names` 即可（不阻断）。

1. `scripts/refresh.sh` (or `node engine/cli.js refresh`) pulls the current season data; once the new season has played a round, run `node engine/cli.js new-season --season 2728` to derive all seven `engine/leagues/*.json` from the teams that actually appear (id, season, team count and zones are recomputed; existing files are not overwritten without `--force`). **Team-count guard**: fewer teams than 75% of the template is rejected outright (incomplete data, `--force` included); a different count above that line only warns and needs `--force`.
2. Run `node engine/cli.js refresh` again: tournaments and active leagues are refreshed together, rebuilding `web/data/*.json` and `index.json`.
3. The page picks them up automatically; after 31 May the season is skipped and archived. Teams missing a Chinese name are listed in the output (not blocking) — add them to `names`.

**每日刷新 / daily refresh**

`scripts/refresh.sh` 是 cron 06:30 跑的那一条：国家队 `fetch` → 在赛赛事 `simulate`；俱乐部 `fetch-clubs`（含 `fixtures.csv`）→ 在赛联赛 `simulate-league`；欧战 `fetch-euro` → 在赛欧战 `simulate-euro`。「今天」按 `Asia/Shanghai` 算；单个赛事/联赛/欧战失败会打印错误并继续，最后以非零码退出。国家队数据**下载**失败但本地 `data/history/` 还能读时不整体失败：打印 `⚠` 警告、用本地数据继续，汇总里带上数据截止日。
`scripts/refresh.sh` is the cron 06:30 entry point: national-team `fetch` → `simulate` for live events; club `fetch-clubs` (incl. `fixtures.csv`) → `simulate-league` for live leagues; `fetch-euro` → `simulate-euro` for live European events. "Today" is the `Asia/Shanghai` date; a failing item is reported and skipped, and the run exits non-zero. If the national-team **download** fails but `data/history/` is still readable, the run warns loudly, falls back to the local data and reports the cutoff instead of failing outright.

## 欧冠与解放者杯 / European cups

| 赛事 / Event | id（配置在 `engine/events/euro/`） | 赛制 / Format | 页面数据 |
|---|---|---|---|
| 欧洲冠军联赛（联赛阶段）/ Champions League league phase | `ucl-2026-27` | 36 队单循环 8 轮 → 1–8 直接进 16 强、9–24 打附加赛、25–36 出局；附加赛到 4 强两回合、决赛单场中立场 | `web/data/ucl-2026-27.json` |
| 南美解放者杯 / Copa Libertadores | `copa-libertadores-2026` | 8 组 × 4 队双循环 → 每组前 2 → 16 强起两回合、决赛单场 | `web/data/copa-libertadores-2026.json` |

- **数据 / Data**：football-data.org v4 免费档（`CL`、`CLI`）。`data/api-keys.json` 里放 `{"football-data": "<key>"}`（已 gitignore，绝不提交、不打印）。原始响应缓存到 `data/uefa/<code>-<season>.json`（不入库），6 小时内不重复联网，请求间隔 ≥1.2 秒，HTTP 429 等 60 秒重试一次。
- **命令 / Commands**：`node engine/cli.js fetch-euro CL`（或 `CLI`）→ `node engine/cli.js simulate-euro ucl-2026-27 --sims 10000`；`refresh` 会先 fetch-euro 再 simulate-euro，自动带上在赛季内的欧战赛事。
- **没有赔率 / No odds**：免费档只有比分，页面市场列固定显示「—」并有一句说明；不伪造赔率。
- **赛制近似 / Format approximations**：附加赛与 16 强的配对按 UEFA 公布的固定签位结构，在同组区间内随机分配（真实是抽签）；8 强、4 强的首回合主场同样按名单顺序近似；总比分平按点球五五开（不单独建模加时）。解放者杯 16 强按「小组第一抽小组第二、同组回避」随机近似；API 已给出的具体对阵与真实比分优先，所以现在的解放者杯只剩决赛在模拟。
- **拟合 / Pool**：欧战队名按配置的 `modelNames` 归一到 football-data.co.uk 写法，和国内联赛共用同一个 Dixon-Coles 拟合；南美俱乐部不在 CSV 里，只有本赛事的比赛可定级。
- **单池结论 / Single pool**：加入葡超、荷甲、比甲、苏超两级、土超、希超后，五大联赛测试集 RPS 0.200181 → 0.200218（+0.000037）、log-loss 0.985091 → 0.985190（+0.0001），远小于 0.002 的判定线，因此国内联赛与欧战共用一个池（不做双池），`engine/clubmodel.json` 的 test 数字按新池重跑。
  Adding Primeira Liga, Eredivisie, Belgian Pro League, both Scottish tiers, Süper Lig and Super League Greece moved the big-five test RPS from 0.200181 to 0.200218 (+0.000037) and log-loss from 0.985091 to 0.985190 (+0.0001), far below the 0.002 threshold, so there is a single pool for domestic leagues and European events.

数字取自 `engine/clubmodel.json`（`tuning.test`、`season.test`）与 `engine/model.json`（`tuning.test`），改模型后必须重跑并更新这几张表。

**比赛级 / Match level（1X2，越低越好 / lower is better）**

| 数据集 / Dataset | | RPS ↓ | log-loss ↓ | 命中率 / hit rate | ECE ↓ |
|---|---|---|---|---|---|
| 五大联赛 17/18–25/26（16,111 场） | 模型 / model | 0.2002 | 0.9852 | 52.7% | 0.0052 |
| | 市场 / market | **0.1944** | **0.9662** | **53.9%** | 0.0056 |
| | Elo 基线 / baseline | 0.2065 | 1.0748 | 52.2% | 0.0408 |
| 国家队 2017–2026（20 届、911 场） | 模型 / model | **0.1742** | **0.9085** | 58.9% | 0.0234 |
| | Elo 基线 / baseline | 0.1757 | 0.9444 | 59.5% | — |
| | 频率基线 / base rates | 0.2277 | 1.0691 | — | — |

如实说：**比赛级上模型不如市场**（RPS 0.2002 vs 0.1944，log-loss 0.9852 vs 0.9662）。市场知道伤停和阵容，模型只知道比分历史。
To be clear: **at match level the model is worse than the market** (RPS 0.2002 vs 0.1944, log-loss 0.9851 vs 0.9662). The market knows injuries and line-ups; the model only knows scorelines.

**赛季级 / Season level（名次概率 Brier，越低越好）**

| 17/18–25/26，n = 2,568 个球队-赛季-检查点 | title | top4 | bottom3 | 平均 / mean |
|---|---|---|---|---|
| 固定实力 / fixed strength（σ=0） | **0.01403** | 0.05026 | **0.06331** | 0.04254 |
| 含实力不确定性 / with uncertainty（σ=0.05） | 0.01407 | **0.05008** | 0.06343 | **0.04252** |

σ 只在 1314–1617 上选（候选 0–0.30，每检查点 2,000 次模拟），落到 0.05；测试赛季上两者基本打平，说明名次概率没有系统性过度自信。title 校准：预测 80–95% 夺冠的球队实际 87.9% 夺冠（33 个球队-赛季-检查点）。
σ was tuned on 1314–1617 only and landed on 0.05; on the test seasons the two modes are level, so the position odds are not systematically overconfident. Title calibration: teams given an 80–95% chance won 88% of the time (33 team-season-checkpoints).

调参划分 / Tuning split：俱乐部只用 13/14–16/17（7,304 场，RPS 0.1983），国家队只用 2010–2016（16 届、559 场，RPS 0.1936）；17/18 以后与 2017 年以后只用于报告。
Clubs are tuned on 13/14–16/17 only; internationals on 2010–2016 only. Everything later is reporting.

## 已知局限 / Known limits

- 模型只用比分历史：无伤停、阵容、转会、赛程密度、天气、裁判，也不读新闻。
- 淘汰赛点球按五五开；数据集比分含加时、不含点球。
- 小组同分规则按公开规则近似（法甲为近似、意甲附加赛按五五开）；第三名组合表拿不到官方版本时用 `thirdAllowed` 约束近似，页面上会标注。
- 队名用 football-data.co.uk 写法（欧战配置里另有 `modelNames`：把 API 的写法映射回 CSV，例如 `FC Bayern München` → `Bayern Munich`）。
- 欧战（欧冠/解放者杯）免费数据档没有赔率，页面上没有市场对照；附加赛/16 强配对与 8 强、4 强首回合主场按官方结构随机近似（真实是抽签）；南美俱乐部没有国内联赛数据，只能靠本赛事比赛定级。

- Scorelines only: no injuries, line-ups, transfers, congestion, weather or referees.
- Knockout penalties are 50/50; the dataset includes extra time but not shootouts.
- Group tie-breaks approximate the published rules; third-place pairings fall back to a constraint when no official table exists, and the page says so.
- Team names follow football-data.co.uk spelling (the European configs carry `modelNames` mapping the API spelling back to the CSVs, e.g. `FC Bayern München` → `Bayern Munich`).
- The free European tier carries no odds, so there is no market comparison there; play-off and round-of-16 pairings, and home order in the quarters and semis, follow the official bracket with random assignment (the real thing is a draw); the South American clubs have no domestic data and are rated from Libertadores matches only.
